# denuncias.sobei.org.br

Canal Oficial e Seguro de Denúncias da SOBEI (Sociedade Beneficente Equilíbrio de Interlagos).

## Funcionalidades
- **Relato Seguro:** Registro de denúncias de forma anônima ou identificada.
- **Protocolo Único:** Geração de identificador rastreável (formato `AAA-000-000`).
- **Acompanhamento de Status:** Consulta pública do andamento da apuração sem necessidade de login.

## Execução Local
```bash
npm install
npm run dev
```
Porta padrão: `http://localhost:3001` (configurada para evitar conflito com os outros portais).
